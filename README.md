# 自明 · SELF

给自己用的生活管理工具：以「今天」为入口，安排任务、坚持习惯、记录收支和管理会员。

当前为 **0.2 开发预览**。参考滴答清单、Microsoft To Do 的日常任务交互，以及 Loop/uHabits 的打卡状态区分；开源调研与固定版本见 [参考记录](docs/open-source-references.md)。

## 已实现

- 今天：日期切换、快速添加、当日任务、逾期与未安排事项、会员到期提醒、专注摘要。
- 计划：任务创建/编辑/完成/恢复、日期和时间、重要标记、自定义清单名称、四象限分组、便签搜索、25 分钟专注及历史。
- 习惯：每日习惯、最近七天补记、完成/跳过/未完成/未记录、连续完成天数。
- 账本：人民币手动支出/收入/转账/关联退款、整数分金额、超额退款拦截、月度汇总与分类钻取。
- 会员：月/季/年周期、日均成本、续费历史、可选续费账单、暂停/取消/推迟应用内提醒。
- 本地：IndexedDB 事务、刷新保留、多标签页数据更新、PWA 离线缓存、回收站、JSON 导出和经过预览与校验的备份恢复。
- 计划补全：日/周/月日历、桌面拖拽与移动端长按、时长调整和重叠标识；每日/每周/每月/工作日及自定义间隔重复，区分单次和后续修改，保留实际完成历史。
- 倒计时：日期时间、到期保留、按天循环、完成历史，临近事项进入今天页。
- 同步：可选单用户 Node/SQLite 服务，客户端 AES-GCM 加密、修订号防覆盖；三方逐记录合并，不同记录自动合并，同记录冲突明确选择；跨记录退款超额仍被拦截，两端原版本均备份。
- 账户设备：私人账户标识、每设备独立令牌、最近访问时间、所有者撤销权限；服务只保存令牌哈希。
- 原生：Windows Tauri 2 NSIS 安装包、Android Capacitor 8 测试 APK；系统通知需主动开启。Windows 托盘后台提醒，Android 系统非精确提醒；原生 JSON 备份保存/分享。

**仍未验收**：vivo X300 Pro 实机通知、系统省电/重启恢复、两台原生设备的离线及 HTTPS 同步、通知快捷操作/免打扰、正式发行签名和账号完整注销流程。Windows 退出托盘后不会提醒；Android 强行停止/省电限制可能延迟或阻止通知。支付识别、预算、物品、投资与运动属于后续阶段。本版仍不是 PRD P0 全量验收通过。

## 安装包

原生安装包由 [Native packages](https://github.com/lizhengda0525-sudo/SELF/actions/workflows/native.yml) 构建。下载最新通过运行的 `SELF-windows-x64`（解压后运行 EXE）或 `SELF-android-test-apk`（解压后安装 APK）。具体版本和验收边界见 [原生安装与验证](docs/native.md)。测试 APK 使用调试签名，Windows 安装包未配置发行证书。

0.2 会迁移 0.1 备份和本机数据库到 schema 2。请先导出备份，再升级所有同步设备；旧客户端会拒绝新格式，不能混用。浏览器和原生应用各有独立本地存储，需要导出/导入或同步迁移。

## 本地运行

使用 Node.js 24 与 pnpm 11（项目锁定 pnpm 11.19.0）。

```sh
pnpm install
pnpm dev
```

打开 http://127.0.0.1:4173 。开发模式用于界面开发。离线缓存需要生产构建：

```sh
pnpm build
pnpm preview
```

首次联网访问并完成缓存后，可离线打开同一地址。不同浏览器、端口和协议有独立的本地账库。清除浏览器站点数据会清空本机记录，请主动导出备份。

## 可选同步服务

没有服务器时保持「仅本机」，无需登录。想启用同步时，使用独立随机令牌启动服务。PowerShell 示例（不输出令牌）：

```powershell
$env:SELF_SYNC_TOKEN = node -e "process.stdout.write(require('node:crypto').randomBytes(32).toString('hex'))"
pnpm build
pnpm server
```

服务默认在 127.0.0.1:4174，同时提供客户端和 `/api/sync`。开发/预览服务 4173 已将 `/api` 代理到 4174。在设置页输入运行进程对应的访问令牌，第一次点击生成密钥并妥善保存下载的文件，所有者可在“账户与设备”中为其他设备创建独立令牌，其他设备使用自己的令牌和同一密钥。请通过自己的密码管理器保管令牌，不要提交到 Git。

手机远程访问需由部署者配置 HTTPS 反向代理到服务；不会自动配置域名、公开服务器或上传真实数据。服务只处理一个用户的账库，无公开注册，也不提供跨域通配访问。服务器默认数据库 `data/sync.sqlite` 不入库，应自行备份。服务器进程重启必须使用原访问令牌。

本地数据与 JSON 备份未做应用层加密。同步密钥不会发送到服务器，也不会持久化；丢失密钥且无本地数据/导出备份时无法解密服务器快照。无密钥轮换服务。

同步是手动触发。传输仍为加密快照；客户端使用上次同步基准逐记录合并。同条记录的不同修改需要明确选择，独立新增或单端修改自动保留；金额关系校验失败时需一起处理相关账单。双方同步前快照在历史备份中可导出。正在运行的计时器只留在设备本地，结束后的专注记录才共享。

## 数据口径

- 仅 CNY；金额内部为整数分；转账不计收支。
- 退款必须关联支出，累计不得超额；在退款发生月抵扣原分类，不回写原支出金额。
- 会员服务期为 `[开始日, 结束日)`，月末按原始日锚定。显示费用是周期费用或折算预计费用，不等于实际扣款。
- 习惯每日一个状态；跳过不增加连续天数，也不中断连续段；历史缺失或未完成会中断连续段。今天尚未打卡时不会提前中断。
- 系统通知仅在用户开启后安排；浏览器关闭页面后无法提醒。第三方来源未接入，会员「自动续费」只记录状态，不操作外部扣款。
