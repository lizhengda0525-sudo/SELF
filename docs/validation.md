# 0.1 开发里程碑验证

日期：2026-09-14。环境：Windows、Node 24.19.0、pnpm 11.19.0、Chromium 153。使用测试数据和内存同步服务器，无真实个人数据或第三方账号。

## 自动化验证

- `pnpm test`：15 项通过。覆盖整数金额解析、月末/闰年周期、转账/待确认排除、跨月退款与超额退款、关联删除、会员历史与账单原子变更、习惯状态和连续段、导入校验、暂停计时、本机并发写入与回滚、加密/篡改检测、同步鉴权及并发 CAS。
- `pnpm build`：TypeScript 检查与 Vite 生产构建通过，生成离线 Service Worker 与 PWA manifest。
- `pnpm test:e2e`：3 条完整场景通过。真实浏览器验证任务添加/完成/刷新、习惯打卡、手动记账、超额退款拦截、会员续费生成账单、回收站恢复、断网后保存完成再刷新、手机六页面无横向溢出；独立设备同步、显式冲突及历史备份；同源多标签页金额编辑冲突与 JSON 导出/恢复。
