# ADR 001：自明首个开发版本

状态：选定；2026-09-14。本次是可运行的开发里程碑，不是 PRD P0 发布验收完成。

## 技术路线

- 共享业务层与界面：React + TypeScript + Vite；移动端底部导航、Windows 桌面侧栏。先提供可离线运行的浏览器/PWA 客户端。Android 后续以 Capacitor 接入系统通知；Windows 后续以 Tauri 2 包装。当前不宣称已有 APK/EXE。
- 本地优先：Dexie / IndexedDB。写入事务成功后才能展示保存成功；页面重载与多标签页由 liveQuery 刷新。不能依赖定时写入内存快照。浏览器数据尚未应用层加密，依赖系统账号和磁盘保护；清除站点数据会丢失本机记录，因此提供 JSON 导出。
- 金额：本版仅 CNY，使用整数分，字符串解析避免浮点乘法误差。退款必须关联原支出，累计退款不能超额；转账不计入收支。会员周期历史与可选续费账单一次事务保存。
- 日期：日历日期 YYYY-MM-DD 与时刻分离，月周期按原始日锚定并钳制月末，周期采用 [开始日, 结束日)；审计时间使用 UTC ISO。
- 同步：可选的单用户自托管 Node 24 + SQLite 服务，保存 AES-256-GCM 加密的整个账库快照。CAS 修订号防覆盖，冲突保留本地与远端，需用户选整库版本，并先备份落选版本。本版保守地使用整库冲突，下一步细化到单条记录。未连接时明确显示仅本机。
- 账号与设备：首版使用单用户服务访问令牌，无开放注册；设备 ID 仅在本机生成。两个设备输入相同服务器令牌和 256 位同步密钥。凭据只在页面内存保存，刷新需重填。
- 传输：生产必须 HTTPS；仅回环地址允许开发 HTTP。服务默认监听 127.0.0.1，无通配 CORS，由同源代理提供访问。服务器令牌由部署者设置；不得写入仓库。
- 密钥：浏览器随机生成 32 字节 AES 密钥，用户自行保存并在其他设备输入。密钥不发给服务器，不持久化在浏览器。尚无密钥轮换/恢复服务。JSON 导出为明文且明确标识。
- 附件：本版本不采集、不存储；后续使用独立加密对象存储，不将凭证原文放入默认同步负载。
- 第三方权限：无支付、银行、健康、遥测接入。仅应用内到期提醒；不模拟后台系统通知。后续在 vivo X300 Pro 实测通知权限拒绝、后台限制、重启恢复、授权支付通知字段、Health Connect 数据来源与重复记录；未通过则保留手工入口。

## 交付边界

实现任务 CRUD / 日期与时间 / 四象限归类、手动收支转账退款、月度分类分析、会员周期与续费历史、便签、基础专注、本地回收站、JSON 导出与经预览的恢复、可选加密同步及冲突处理。

仍需完成：日周月拖拽日历、重复任务、倒计时、系统通知、账号管理、细粒度同步冲突、原生安装包与目标机验收。预算、支付识别、物品、投资、运动按后续阶段推进。
