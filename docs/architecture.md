# ADR 001：自明开发版本（0.2 修订）

状态：选定；2026-09-14。本次是可运行的开发里程碑，不是 PRD P0 发布验收完成。

## 技术路线

- 共享业务层与界面：React + TypeScript + Vite；移动端底部导航、Windows 桌面侧栏。先提供可离线运行的浏览器/PWA 客户端。Android 以 Capacitor 8 接入本地通知与备份分享；Windows 以 Tauri 2 提供 NSIS 安装包、单实例、托盘提醒与保存对话框。
- 本地优先：Dexie / IndexedDB。写入事务成功后才能展示保存成功；页面重载与多标签页由 liveQuery 刷新。不能依赖定时写入内存快照。浏览器数据尚未应用层加密，依赖系统账号和磁盘保护；清除站点数据会丢失本机记录，因此提供 JSON 导出。
- 金额：本版仅 CNY，使用整数分，字符串解析避免浮点乘法误差。退款必须关联原支出，累计退款不能超额；转账不计入收支。会员周期历史与可选续费账单一次事务保存。
- 日期：日历日期 YYYY-MM-DD 与时刻分离，月周期按原始日锚定并钳制月末，周期采用 [开始日, 结束日)；审计时间使用 UTC ISO。
- 同步：可选的单用户自托管 Node 24 + SQLite 服务，保存 AES-256-GCM 加密的整个账库快照。CAS 修订号防覆盖。基于独立深拷贝的 serverBase 做三方逐记录合并；同条记录不一致需显式选择，跨记录金额关系仍须通过完整校验；双方原版本备份。无已知基准的旧 dirty 库保守地请求冲突选择。未连接时明确显示仅本机。
- 账号与设备：单用户服务无开放注册。所有者令牌管理账号下的独立设备令牌，服务仅保存 SHA-256 哈希、名称、创建/访问/撤销时间；设备不能管理其他设备。各设备使用独立令牌和同一 256 位同步密钥。凭据只在页面内存保存，刷新需重填。
- 传输：生产必须 HTTPS；仅回环地址允许开发 HTTP。服务默认监听 127.0.0.1，无通配 CORS；原生本机应用固定来源白名单支持预检，浏览器使用同源代理。服务器令牌由部署者设置；不得写入仓库。
- 密钥：浏览器随机生成 32 字节 AES 密钥，用户自行保存并在其他设备输入。密钥不发给服务器，不持久化在浏览器。尚无密钥轮换/恢复服务。JSON 导出为明文且明确标识。
- 附件：本版本不采集、不存储；后续使用独立加密对象存储，不将凭证原文放入默认同步负载。
- 第三方权限：无支付、银行、健康、遥测接入。已接入原生本地通知：Android 非精确系统调度，Windows 进程内调度且窗口关闭后驻留托盘，进程退出则停止。浏览器只在页面打开时提醒。仍需在 vivo X300 Pro 实测通知权限拒绝、后台限制、重启恢复、授权支付通知字段、Health Connect 数据来源与重复记录；未通过则保留手工入口。

## 交付边界

实现任务 CRUD / 日期与时间 / 四象限归类、手动收支转账退款、月度分类分析、会员周期与续费历史、便签、基础专注、本地回收站、JSON 导出与经预览的恢复、可选加密同步及冲突处理。

本次新增日周月拖拽日历、重复任务、倒计时、原生提醒、设备管理与逐记录合并。仍需完成目标机验收、通知快捷操作/免打扰、正式签名与账号完整生命周期。预算、支付识别、物品、投资、运动按后续阶段推进。
